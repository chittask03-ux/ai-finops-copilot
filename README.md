# 🤖 AI FinOps Copilot (Snowflake + LangGraph)

An intelligent AI-powered FinOps assistant that translates natural language into Snowflake SQL, executes queries, and explains results with evaluation and guardrails.

---

## 🚀 Features

- Natural Language → SQL (Snowflake)
- Guardrails (Prevents destructive queries)
- Self-healing SQL (Retry & Fix)
- Result Explanation (LLM-powered)
- Evaluation Layer (Confidence + Score)
- Memory (Conversation-aware queries)
- FastAPI backend
- Streamlit UI
- Dockerized deployment
- AWS EC2 deployment ready
